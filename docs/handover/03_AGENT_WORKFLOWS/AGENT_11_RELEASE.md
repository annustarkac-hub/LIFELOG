# Agent 11 — Release & Handover Engineer

Role: Android release engineer.

Tasks:
1. Verify clean release build.
2. Configure application ID, versioning and release build types.
3. Prepare signing instructions. Do not create or commit private signing keys.
4. Build APK and AAB if environment permits.
5. Verify artifact install/signature and record SHA-256 checksums.
6. Prepare Play Store listing checklist and privacy disclosures.
7. Package source, documentation, test report, known limitations and build instructions.
8. Ensure repository and signing ownership remain with the product owner.
9. Produce final handover checklist.

Do not claim Play Store publication unless actually completed by account owner.
Deliverables: release artifacts, checksums, release notes, handover report.
