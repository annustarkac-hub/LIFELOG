# Agent 10 — QA & Test Engineer

Role: Android QA engineer.

Tasks:
1. Build a test matrix across supported Android API levels and OEMs.
2. Test Usage Access granted/revoked.
3. Test historical query bounds and gaps.
4. Test app foreground transitions and duplicate events.
5. Test reboot, force-stop, Doze, battery saver and app update.
6. Test timezone/date changes and daylight-saving boundaries.
7. Test backup/restore, corrupt backup, older schema and insufficient storage.
8. Test performance with large local history.
9. Verify no data is fabricated.
10. Produce a test report with pass/fail, evidence, device/API and severity.

P0 blocker bugs must be fixed before release.
Deliverables: QA report, regression suite, release recommendation.
