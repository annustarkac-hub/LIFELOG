# Release Checklist

## Before release
- [ ] P0 acceptance criteria passed
- [ ] QA report approved
- [ ] Security/privacy review complete
- [ ] No mock data in production
- [ ] App version and versionCode set
- [ ] Application ID confirmed by owner
- [ ] App icon and launch assets approved
- [ ] Privacy policy prepared and reviewed
- [ ] Permission declarations reviewed
- [ ] Data safety answers prepared accurately
- [ ] Offline behavior verified
- [ ] Backup/restore tested

## Signing
- [ ] Signing key generated/managed by owner
- [ ] Signing key not committed to source control
- [ ] Recovery copy stored securely by owner
- [ ] Release APK/AAB signed
- [ ] SHA-256 checksums recorded

## Handover
- [ ] Source repository transferred/owner access confirmed
- [ ] Build instructions verified from clean checkout
- [ ] Database schema/migrations documented
- [ ] Known limitations documented
- [ ] Dependency/license list delivered
- [ ] Test report delivered
- [ ] APK/AAB delivered
- [ ] No developer-only credentials remain
